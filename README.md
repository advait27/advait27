## What I'm Building Now

**Founding Engineer / AI Consultant — Frensei (ClawbackVault AI)**

Architecting and shipping an AI-first surveillance and signal-intelligence platform on the Claude Developer Platform (Claude Sonnet 4.6), end to end — from applied-AI architecture to product strategy.

- 🎯 **Targeted-surveillance watchlist** replacing full-inbox scanning — cut LLM token spend per broker by **80–90%** while strengthening privacy compliance
- 🔍 **Four-tier signal-detection engine** classifying client-churn signals across **15+ behavioural categories** with tiered confidence scoring and a full evidence-trail audit log
- 🔐 **Privacy-first pipeline**: header scan → PII-masked body fetch → LLM classification, with email bodies processed in-memory and never persisted (CASA Tier 2, Google OAuth Restricted Scope)
- 🛡️ **Security & governance**: AES-256-GCM encryption at rest, PII masking ahead of every LLM call, prompt-injection protection, OAuth revocation recovery, GDPR data-portability export, Supabase row-level tenant isolation (EU-West / Asia-Pacific)
- 📊 Built the **model evaluation framework** — signal precision, confidence calibration, cost/latency trade-offs — used to select the right foundation model for the use case
